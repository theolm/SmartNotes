# Domain docs

This repo uses a single-context layout.

- Domain language and context: `CONTEXT.md` at repo root
- Architecture and required patterns: `docs/architecture.md`
- Visual design system: `docs/DESIGN.md`

Read `CONTEXT.md` and `docs/architecture.md` before proposing changes to domain models, architecture, or terminology. Read `docs/DESIGN.md` before changing UI.

Do not create ADRs or files under `docs/adr/`. Record architecture decisions directly in `docs/architecture.md`.
